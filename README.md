# Valoria Studio

אתר תדמית בעברית וב־RTL, שנבנה ב־HTML, CSS ו־JavaScript ללא תלות בספריות בזמן ריצה.

## צפייה מקומית

אפשר לפתוח את `index.html` ישירות בדפדפן. להפעלת שרת מקומי:

```sh
npm run dev
```

ב־PowerShell שחוסם קובצי ps1 ניתן להשתמש ב־`npm.cmd run dev`.
הכתובת המקומית: `http://127.0.0.1:4173`.

## עדכון פרטי הקשר

ערכו את `site-config.js`:

- `phoneDisplay`: המספר שיוצג באתר. כרגע `050-000-0000`, להמחשה בלבד.
- `whatsappNumber`: המספר האמיתי בפורמט בינלאומי, ספרות בלבד וללא סימן `+`.
- `email`: כתובת המייל האמיתית, אם רוצים שליחה באמצעות תוכנת המייל במקום WhatsApp.

כל עוד לא הוגדר יעד אמיתי, הטופס וה־WhatsApp מציגים הודעת תצוגה מקדימה. הפרטים אינם נשלחים או נשמרים. לאחר הגדרת WhatsApp, הטופס פותח הודעה מוכנה שהמבקר שולח בעצמו. אם מוגדר רק מייל, נפתחת טיוטה בתוכנת המייל. אין שירות שרת לשליחת מייל אוטומטית.

## תוכן ומיתוג

- שני הלוגואים המקוריים נשמרו ב־`images/logos` ללא שינוי. האתר משתמש בגרסאות שקופות וחתוכות שלהם (`valoria-logo-light.webp`, `valoria-logo-dark.webp`), כדי שלא יופיע ריבוע רקע על משטחים בהירים או כהים.
- הכיתוב בס״ד, שהופיע בפינת קובצי הלוגו, מוצג כטקסט מעל סרגל הניווט במקום להיות חלק מהתמונה.
- פרטי המייסדים אינם מומצאים; אפשר להוסיף שמות ותמונות כשיהיו זמינים.
- שני הפרויקטים בתיק העבודות הם קונספטים עצמאיים ומסומנים כך. אין לקוחות או המלצות פיקטיביים.
- דפי הקונספט האינטראקטיביים נמצאים ב־`concepts` והאיורים ב־`assets`.
- הגופנים מוגשים מקומית מתוך `assets/fonts`, עם רישיונות OFL לכל אחד: Heebo לטקסט, Frank Ruhl Libre למילות ההדגשה בעברית ו־Cormorant Garamond לאותיות לטיניות ולמספרים.

## מבנה הקוד

- `app.js`: הלוגיקה הבסיסית. טאבים פנימיים (כל פרק נפתח באותו עמוד), תפריט, חלון פרויקט, טופס והעדפת תנועה.
- `fx.js`: שכבת האפקטים. מסך פתיחה, חשיפת כותרות, סמן מותאם, כפתורים מגנטיים, תאורת כרטיסים, הטיית תלת־ממד, פסי טקסט נעים, התקדמות בתהליך ואנימציית שאלות.
- `chrome.js`: אובייקט הכרום החי בפתיח, מצויר ב־WebGL. אם הדפדפן אינו תומך ב־WebGL, מוצג איור ה־SVG המקורי.

מסך הפתיחה מוצג פעם אחת בכל ביקור (לשונית דפדפן). כל האנימציות נכבות כשמופעלת הפחתת תנועה, מהאתר או ממערכת ההפעלה. הסמן המותאם פועל רק עם עכבר.

## בנייה

```sh
npm run check
npm run build
```

הקבצים לפרסום נוצרים ב־`dist`. אין צורך בהתקנת תלויות לבנייה או להפעלה.

## נגישות ובדיקות

האתר כולל ניווט מקלדת, קישור דילוג, תפריט עם ניהול מיקוד, חלון פרויקט נגיש, תוויות לטופס וכפתור להפחתת תנועה. העדפת תנועה מופחתת של מערכת ההפעלה מכובדת אוטומטית. בכל פרק מתעדכנים כותרת הדף וכותרת ראשית לקוראי מסך, וכפתור החזרה של הדפדפן חוזר לפרק הקודם.

נבדק ב־Chrome ברוחבי 320, 360, 390, 650, 768, 1024 ו־1440 פיקסלים בכל שבעת הפרקים; נבדקו ניווט, חלונות פרויקטים, FAQ, טופס, מצב מספר זמני והפחתת תנועה. בדיקת axe אוטומטית בכל הפרקים במחשב ובמובייל הסתיימה ללא ממצאים. בדיקה אוטומטית אינה אישור נגישות מלא; לא בוצעה בדיקה במכשירי iOS פיזיים, ולא נבדקו דפדפני Safari ו־Firefox.
